The ultimate landing page template for your developer tool.

### What is this?

This is a landing page template for a developer tool. The template is built with Next.js, TailwindCSS, and Framer Motion, optimized for showcasing developer tools and services.

### Who is this for?

You are launching a new developer tool or service and need a professional, eye-catching landing page to showcase your product's features and attract developers.

### Why should I use this?

- ✅ Save 500+ hours of work
- ✅ No need to learn advanced animations
- ✅ Easy to configure and change
- ✅ 1-click download and setup
- ✅ 5 minutes to update the text and images
- ✅ Deploy live to Vercel

### Features

- 1x Landing Page with 13 sections
  - Header Section
  - Hero Section
  - Logos Section
  - Examples Section
  - Use Cases Section
  - Features Section
  - Statistics Section
  - Testimonials Section
  - Pricing Section
  - Community Section
  - Blog Section
  - CTA Section
  - Footer Section
- 1x Blog using MDX
- Dark mode support
- 100% Mobile responsive
- Full SEO coverage
- Dynamic OpenGraph images for every page
- Tons of animations / micro-interactions
- Clean and maintainable code
- Global constants and variables for color, text, and more

### Dependencies

- Next.js 15
- React 18.3
- TypeScript 5
- TailwindCSS 3.4
- Framer Motion 11.3
- next-themes 0.3.0
- radix-ui
- shadcn/ui
