## Page Flow Summary

1. **Navigation**: Logo left, CTA buttons right
2. **Hero**: Main value prop with dual CTAs
3. **Social Proof Badges**: Key metrics (24/7, tool integration, 6-week)
4. **Product Demo**: Email interface showing AI agent in action
5. **Value Proposition**: Mission statement with bullet points
6. **Stats Panel**: Key numbers and customer testimonial
7. **Trust Bar**: Major company logos
8. **Services Grid**: Bento-style layout of offerings
9. **Footer Metrics**: Performance indicators

- Background: Dark/Black
